# 任务三：为更小的输入尺寸选择阈值

用同一份 `annotations.csv`、同一个 `yolo11n.pt`、同一个 `sports ball` 类别和 `IoU >= 0.50` 的匹配规则，比较三组设置：

| 组 | 输入尺寸 | 置信度阈值 | 变量 |
| --- | ---: | ---: | --- |
| A | 640 | 0.10 | 基准 |
| B | 320 | 0.10 | 相对 A 只改尺寸 |
| C | 320 | 0.25 | 相对 B 只改阈值 |

验证集是仓库的 14 张 RT 图：10 张完整球（regular）、2 张边缘球（edge）、2 张无球（empty）。

## 交付文件

| 文件 | 用途 |
| --- | --- |
| `task03-stats.csv` | A/B/C 三组统计表，每项都有分子/分母 |
| `rt-025-ABC-comparison.png` | 第 25 帧 A/B/C 对照图 |

| `run_task03.sh` | 三组评测 + 生成图表的复跑入口 |

## 统计结果

| 组 | 尺寸 | 阈值 | 完整球匹配 | 边缘球匹配 | 无球误报 | 全部有球匹配 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| A | 640 | 0.10 | **3/10** | **1/2** | **0/2** | **4/12** |
| B | 320 | 0.10 | **3/10** | **0/2** | **0/2** | **3/12** |
| C | 320 | 0.25 | **2/10** | **0/2** | **0/2** | **2/12** |

分母说明：

- 完整球：10 张，对应 `regular`。
- 边缘球：2 张，对应 `edge`。
- 无球：2 张，对应 `empty`。
- 全部有球：12 张 = 10 张完整球 + 2 张边缘球。
- 无球误报的分子是“有检测框的无球帧数”，分母是无球帧数。

## 逐帧观察

关键帧：

| 帧 | 分组 | A：640/0.10 | B：320/0.10 | C：320/0.25 |
| ---: | --- | --- | --- | --- |
| 25 | 完整球 | 未检出 | 命中 `0.316`，IoU `0.956` | 命中 `0.316`，IoU `0.956` |
| 275 | 完整球 | 命中 `0.270`，IoU `0.973` | 命中 `0.156`，IoU `0.959` | 未检出 |
| 145 | 边缘球 | 命中 `0.125`，IoU `0.770` | 未检出 | 未检出 |
| 150 | 边缘球 | 未检出 | 未检出 | 未检出 |
| 180、200 | 无球 | 无误报 | 无误报 | 无误报 |

完整球的变化：

- A 和 B 都是 `3/10`，但不是同一组帧。B 检出了第 25 帧，A 没有；A 检出了第 225 帧，B 没有。
- B 到 C 只把阈值从 `0.10` 提到 `0.25`，完整球从 `3/10` 降到 `2/10`，第 275 帧的 `0.156` 被阈值滤掉。
- 第 25 帧说明 320 有时能帮助完整球；第 275 帧说明 320 会降低置信度，阈值一提高就容易丢球。

边缘球的变化：

- A 是唯一检出边缘球的组：第 145 帧 `0.125`，`1/2`。
- B、C 都是 `0/2`，降到 320 后两张边缘球都检不出。
- 第 150 帧三组都没检出，说明只框可见部分时目标太小，640 也救不回来。

无球帧：

- 三组都是 `0/2`，没有误报。降尺寸或降阈值在这两张无球图上没有带来额外误报，但这不足以抵消边缘球的损失。

## 判断

**不采用 320，继续用 640 + `conf=0.10`。**

理由：

1. 320 没有提高完整球命中数：A、B 都是 `3/10`，只是命中的帧不同。
2. 320 丢掉了唯一的边缘球命中：A 是 `1/2`，B 是 `0/2`。任务明确希望“尽量保住边缘球”，这是决定性差异。
3. 三组无球误报都是 `0/2`，320 没有带来误报上的收益。
4. 如果队友因为速度必须用 320，阈值应选 `0.10`（B），不要选 `0.25`（C）：`0.25` 会把完整球从 `3/10` 再降到 `2/10`，边缘球仍然是 `0/2`，没有补偿。
